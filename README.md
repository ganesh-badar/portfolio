## 💻 Running Locally

No npm installs, bundlers, or server dependencies needed!

1. **Clone the repository:**
   ```bash
   git clone https://github.com/ganesh-badar/portfolio.git
   cd portfolio
   ```

2. **Open in browser:**
   - Double-click `index.html` or open in VS Code with **Live Server**.
